# GitHub Practice Project

## Project Description

This project demonstrates basic Git and GitHub workflow.

The project focuses on creating a repository, making meaningful commits,
creating a feature branch, merging the branch, and maintaining project
documentation.

## Objectives

- Understand GitHub repository management
- Create meaningful commits
- Create and use a feature branch
- Merge a feature branch
- Maintain project documentation

## Git Workflow

1. Create repository
2. Create project documentation
3. Make meaningful commits
4. Create feature branch
5. Add a new feature/documentation
6. Create Pull Request
7. Merge the feature branch

## Technologies / Tools

- Git
- GitHub
- Markdown
  ## Completed GitHub Workflow

- Repository created
- Project documentation added
- Multiple meaningful commits created
- Feature branch created
- Pull request created
- Feature branch merged into main
