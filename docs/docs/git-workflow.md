# Git Workflow

## Repository

The project is maintained in a GitHub repository.

## Commit

Commits record meaningful changes made to the project.

## Branch

A feature branch allows changes to be developed separately
from the main branch.

## Pull Request

A pull request is used to review and integrate the feature.

## Merge

After review, the feature branch can be merged into the main branch.

## Workflow

Repository → Branch → Changes → Commit → Pull Request → Merge
